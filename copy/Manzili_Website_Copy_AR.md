**Site:** Arabic pages on `https://manzili.sa/ar`, using the English slugs under `/ar`
**Covers:** sitewide components + 23 pages, including the full Privacy Policy and Terms of Service

## How to Use This File

- Every string in `code format` is final Arabic copy. Paste it exactly as written.
- In a left-to-right editor or viewer, some Arabic strings can look out of order (for example, a final full stop shown at the left). The text itself is correct: copy it as is, and it displays correctly on the RTL page.
- Labels and build notes are in English. Each Arabic page uses the same layout, components and anchors as its English page, and the page and section numbers match the English file.
- `→` shows a link target. Internal links use the `/ar` prefix: `/ar`, `/ar/platform-cse`, `/ar/contact-us`, and so on.
- The navbar, footer, CTA banner, FAQ module and UI strings are built once (Part 1) and reused on the pages that list them.

## Arabic Build Notes (RTL)

1. **Direction:** set `<html lang="ar" dir="rtl">` on all Arabic pages. Mirror layouts (navigation, cards, breadcrumbs, arrows, form fields) from right to left.
2. **Font:** Cairo, the site's existing font, which covers Arabic. Use weight 700 for headings and 400 for body text. Increase Arabic body line height to 1.7–1.8.
3. **Numbers:** Western numerals (0–9) only, exactly as written in the strings.
4. **Mixed text:** brand and system names stay in Latin script inside Arabic sentences (Salesforce, HubSpot, Unreal Engine 5, CRM, Matterport). Wrap each Latin run in `<bdi>` or apply `unicode-bidi: isolate` so it doesn't break RTL order.
5. **Phone numbers and emails:** always render left to right (`dir="ltr"`). Inside Arabic strings, wrap each one in `<bdi dir="ltr">…</bdi>`, so `+966` isn't flipped to `966+` and a trailing ، or . stays on the correct side. Examples: `واتساب: +966 53 484 4986`, the legal contact lines, the form failure message.
6. **Strings that start with Latin text:** set `dir="rtl"` explicitly on the element, never `dir="auto"`. Examples: `Salesforce` rows, `Yardi · Salesforce متصلان`.
7. **Language toggle:** on Arabic pages, show `English` linking to the matching English page. Set `hreflang="ar"` / `hreflang="en"` alternates on both versions.
8. **Canonical tags:** `https://manzili.sa/ar/[slug]`, with a matching `og:url`.
